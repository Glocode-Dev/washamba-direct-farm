# Washamba: Grow Direct

Build a production-ready, highly professional, responsive marketing landing page and corporate website for "Washamba" (an innovative agritech marketplace platform connecting African smallholder farmers directly to buyers and consumers). 

Ensure the styling is modern, clean, and trustworthy, utilizing an "Emerald-to-Forest Green" primary palette (#059669 to #064e3b), clean white/slate backgrounds, and warm amber accents (#d97706) to symbolize agriculture and premium quality. Use modern typography (e.g., Inter, Plus Jakarta Sans, or Geist).

Implement the following complete structure and sections:

1. NAVIGATION BAR:

- Clean glassmorphism layout.

- Left: Dynamic modern typography Logo ("Washamba").

- Center: Links for Features, Marketplace, About Us, Impact, FAQs.

- Right: "Download App" CTA Button with a Google Play Store icon.

2. HERO SECTION:

- Left Column: Bold, clear value proposition: "Connecting Farmers & Buyers Made Easy. Direct from the soil to the market." Sub-headline detailing how Washamba bridges the agricultural gap for fresh, locally-sourced produce without exploitative middle-men.

- Visual CTAs: Prominent green primary button for "Get the App" and an outline secondary button for "Explore the Marketplace".

- Right Column: High-fidelity mockup or clean canvas placeholder representing the Washamba mobile app showing fresh produce cards and farmer metrics.

3. THREE-WAY COHORT VALUE PROP CARDS (Farmers, Buyers, Consumers):

Create a responsive grid showcasing tailored benefits for each target audience:

- Card 1 (Farmers): "Direct Market Access" - Post listings, eliminate middlemen, secure fair, transparent pricing.

- Card 2 (Bulk Buyers): "B2B Supply Integrity" - Direct sourcing for restaurants, hotels, and retail shops with clear logistics.

- Card 3 (Consumers): "Farm-to-Table Freshness" - Order fresh, nutrient-rich, locally sourced produce seamlessly.

4. APP FEATURES MARQUEE / BENTO GRID:

Display modern micro-interaction cards demonstrating:

- Live Product Catalogues (with beautiful grid filters).

- Direct Communication/Chat layer mapping between buyer and producer.

- Safe Mobile-Money integrated marketplace system layout.

5. IMPACT & BRAND ETHOS HIGHLIGHT:

A modern text section with large numerical statistics emphasizing the "Ukulima Sio Ushamba" movement. Subverting the rural narrative by positioning farming as a high-tech, highly respected, and critical economic driver. Include 3 stats layout: 100% Direct Sourcing, 0% Hidden Broker Fees, 3x Farmer Retention.

6. FAQS SECTION:

An interactive multi-item Accordion Component answering standard user questions regarding delivery logistics, payment holding escrow patterns, and how farmers can register their fields.

7. FULL CORPORATE FOOTER:

Include complete columns for Brand Profile, Legal terms (Privacy Policy, Terms of Service), Links to Play Store, and an Email Newsletter capture form.

Make sure the components use Tailwind CSS, include fully accessible interactive states (hover/focus transitions), are fully accessible (semantic HTML), and ready for production hosting. Do not use generic fallback boilerplate text; write descriptive agricultural and agritech content natively across all sections.
