## Project architecture

- Keep the Washamba corporate campaign as a single anchored home route because its navigation is intentionally designed as one continuous landing experience.
- Use semantic tokens from `src/styles.css` and the shared Button primitive for all interactive controls to preserve the brand and accessibility system.
